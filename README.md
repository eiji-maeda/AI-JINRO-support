# AI-JINRO-support

1人の人間プレイヤーが最大9人のAIと対戦する人狼ゲームアプリ。  
Claude / OpenAI / Gemini のAPIキーを設定してプレイできます。  
6つの役職と3つのAIプロバイダーに対応しています。

---

## アプリの使い方

### 初回: 設定

ホーム画面の「設定」から以下を入力:

- プレイヤー名
- AIプロバイダー（Claude / OpenAI / Gemini）
- モデル
- APIキー（「接続テスト」で疎通確認）

### ゲーム開始

1. ホーム画面で「ゲームを始める」をタップ
2. **ゲーム設定画面**でプレイヤー総数（4〜10人）と自分の役職を選択
3. 「ゲーム開始」をタップ

### ゲームの流れ

4. **夜フェーズ**：自分の役職に応じたアクションを選択
5. **昼フェーズ**：AIと議論し、「投票へ」で投票フェーズに進む
6. **投票フェーズ**：処刑したい相手を選んで投票
7. どちらかの陣営が勝利条件を満たすまで繰り返す

### ペルソナ設定（任意）

ホーム画面の「ペルソナ設定」からAIの個性（名前・口調・性格）をカスタマイズできます。  
追加したペルソナはゲームにランダムで参加します。

## 役職一覧

| 役職 | 陣営 | 能力 |
|------|------|------|
| 村人 | 村人 | なし |
| 占い師 | 村人 | 毎晩1人が人狼かどうかを占える |
| 騎士 | 村人 | 毎晩1人を人狼の襲撃から守れる |
| 霊媒師 | 村人 | 処刑された人が人狼かどうかわかる |
| 人狼 | 人狼 | 毎晩1人の村人を襲撃できる |
| 狂人 | 人狼 | 人狼の勝利が目的だが人狼の情報は持たない |

役職の組み合わせはプレイヤー総数に応じて自動決定されます。  
自分の役職はランダムまたは指定から選べます。
