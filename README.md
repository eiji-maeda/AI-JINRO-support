# AI-JINRO-support

1人の人間プレイヤーが最大9人のAIと対戦する人狼ゲームアプリ（Flutter）。  
Claude / OpenAI / Gemini のAPIキーを設定してプレイできます。  
6つの役職と3つのAIプロバイダーに対応しています。

---

## 必要なもの

| ツール | バージョン |
|--------|-----------|
| Flutter SDK | 3.x 以上（確認済み: 3.41.2） |
| Dart SDK | 3.x 以上（Flutter同梱） |
| Android Studio / Xcode | エミュレーター or 実機接続用 |
| AIプロバイダーのAPIキー | Claude / OpenAI / Gemini のいずれか |

---

## セットアップ

### 1. リポジトリのクローン

```bash
git clone <repository-url>
cd AI_JINRO
```

### 2. 依存パッケージのインストール

```bash
flutter pub get
```

### 3. 起動

**Androidエミュレーターまたは実機で起動（推奨）:**

```bash
flutter run
```

接続されているデバイスが複数ある場合はデバイスを選択:

```bash
flutter devices          # デバイス一覧を確認
flutter run -d <device-id>
```

**リリースビルド（実機向け・高速）:**

```bash
flutter run --release
```

## アプリの使い方

### 初回: 設定

ホーム画面の「設定」から以下を入力:

- プレイヤー名
- AIプロバイダー（Claude / OpenAI / Gemini）
- モデル
- APIキー（「接続テスト」で疎通確認）

### ゲーム開始

1. ホーム画面で「ゲームを始める」をタップ
2. **ゲーム設定画面**でプレイヤー総数（4〜10人）と自分の役職を選択
3. 「ゲーム開始」をタップ

### ゲームの流れ

4. **夜フェーズ**：自分の役職に応じたアクションを選択
5. **昼フェーズ**：AIと議論し、「投票へ」で投票フェーズに進む
6. **投票フェーズ**：処刑したい相手を選んで投票
7. どちらかの陣営が勝利条件を満たすまで繰り返す

### ペルソナ設定（任意）

ホーム画面の「ペルソナ設定」からAIの個性（名前・口調・性格）をカスタマイズできます。  
追加したペルソナはゲームにランダムで参加します。

## 役職一覧

| 役職 | 陣営 | 能力 |
|------|------|------|
| 村人 | 村人 | なし |
| 占い師 | 村人 | 毎晩1人が人狼かどうかを占える |
| 騎士 | 村人 | 毎晩1人を人狼の襲撃から守れる |
| 霊媒師 | 村人 | 処刑された人が人狼かどうかわかる |
| 人狼 | 人狼 | 毎晩1人の村人を襲撃できる |
| 狂人 | 人狼 | 人狼の勝利が目的だが人狼の情報は持たない |

役職の組み合わせはプレイヤー総数に応じて自動決定されます。  
自分の役職はランダムまたは指定から選べます。

## トラブルシューティング

**`flutter run` でデバイスが見つからない場合:**
```bash
flutter doctor    # 環境の問題を確認
```

**依存関係のエラーが出る場合:**
```bash
flutter clean
flutter pub get
flutter run
```

**接続テストでエラーが出る場合:**
- APIキーのスペルを確認
- 選択したモデルがプランで利用可能か確認
- ネットワーク接続を確認
